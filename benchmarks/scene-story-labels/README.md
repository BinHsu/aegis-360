# Scene-story benchmark labels

These privacy-safe configs are benchmark evidence, not product-time human
inputs. They contain closed observations only and must be bound to the exact
external `scene-story-review-packet` before use.

The initial Old Ghost Road labels are agent source-context review. The owner
accepted cardinal framing coverage but did not label story role. The agent
compared 30-second context, one-second cut sequences and a five-second full-film
timeline. Do not describe these files as owner ground truth. A later human or
model review must use separate provenance rather than overwrite these files.
